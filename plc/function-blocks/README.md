# Function Blocks

This folder contains anonymized descriptions and code examples of PLC function blocks used in the meter tracking system.

## Function Blocks

- `calc-delta-t-fb.st` — measures digital sensor pulse duration
- `cut-point-fb.st` — captures valid meter values during counter reset/cut events
- `mb-reset-fb.st` — handles Modbus channel reset/recovery logic
- `line-analysis-full-fb.md` — documents the main production line analysis function block and its role in the system.
